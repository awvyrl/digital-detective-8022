## 4. My understanding

### Task 1.1 - Trace One Activity Using IPOS
**Chosen Activity:** Writing and saving a Python script on my laptop.

| Stage | What happens in your example? | Hardware / component |
| :--- | :--- | :--- |
| **Input** | I type lines of Python code and press `Cmd + S` to save the file. | Keyboard |
| **Processing** | The processor decodes the keystrokes, updates the text buffer in memory, and prepares the file data to be written. | CPU (Processor) and RAM (Memory) |
| **Output** | The typed characters and save confirmation appear immediately on the display. | Screen / Monitor |
| **Storage** | The `.py` file is written permanently onto the internal drive so it remains saved after shutting down. | Solid State Drive (SSD) |

**How the activity moves through IPOS:** Keystrokes enter as electrical input signals, the CPU and RAM process those signals into updated text, the screen outputs real-time visual feedback, and saving transfers the data from temporary RAM into permanent SSD storage.
