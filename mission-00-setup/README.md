## 1. Task / objective
Create a properly named local project folder, initialize a Git repository, set up the folder and README structure for all missions, and publish the initial structure to a public GitHub repository.

## 2. Work completed

## 3. Commands / tools used
* `python3 --version` — Checks the installed Python 3 version.
* `git --version` — Checks the installed Git version.
* `mkdir` / `mkdir -p` — Creates the project directory and all mission subdirectories.
* `cd` — Navigates into the project directory.
* `touch` — Creates empty `README.md` files and `number_converter.py`.
* `git init -b main` — Initializes a new local Git repository using `main` as the default branch.
* `git remote add origin` — Links the local repository to the remote GitHub repository.
* `git add .`, `git commit`, `git push` — Stages, saves, and uploads the setup files to GitHub.

## 4. My understanding
* **Repository Name:** `digital-detective-8022`
* **Tools Checked:** Python 3 (Python 3.9.6) and Git (git version 2.55.0).
* **What a repository is:** A Git repository is a project workspace tracked by version control that records snapshots (commits) of files over time so changes can be reviewed or restored safely.
* **Why the folder structure is organized by mission:** Separating each mission into its own folder keeps topics modular, prevents files from getting mixed up, and makes it easy to document, commit, and verify one mission at a time.
