# The Digital Detective — System Exploration Report

This repository contains my Diwali Independent Learning Assignment. Through a sequence of nine missions, I explore how a computer processes data, practice Terminal commands, inspect operating system behavior, run Python programs, convert number systems, use Git/GitHub workflows, and examine computer networking.

## My Learning
* **Command-Line & OS Fundamentals:** I learned how to navigate folders, manage files safely, use command flags and pipes, and inspect running processes and file permissions in Terminal.
* **How Programs & Data Work:** I learned the difference between compilers and interpreters, converted numbers across decimal, binary, and hexadecimal systems, and built a working Python number converter.
* **Version Control & Collaboration:** I learned how Git tracks changes through staging and commits, and how branches and Pull Requests let developers work safely on updates.
## Workflow Note
Each mission is completed, documented in its own `README.md`, committed separately with a descriptive commit message, and pushed to GitHub before starting the next mission.
