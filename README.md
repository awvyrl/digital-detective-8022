# The Digital Detective — System Exploration Report

This repository contains my Diwali Independent Learning Assignment (**The Digital Detective**). Through nine sequential missions, I investigated how computers process data, practiced command-line operations, examined operating system management, compared program execution models, worked with binary and hexadecimal number systems in Python, used Git/GitHub collaboration workflows, and explored computer networking.

## Topics Explored
* **Computer Fundamentals:** Input–Process–Output–Storage (IPOS) flow, hardware vs. software classification, and everyday computer systems.
* **Terminal & CLI:** Directory navigation, safe file operations, command flags, output piping, and package managers.
* **Operating Systems:** Kernel and storage inspection, running processes and PIDs, absolute vs. relative paths, file permissions (`r`, `w`, `x`), and core OS responsibilities.
* **Program Execution:** Running Python 3 scripts and comparing compilers vs. interpreters.
* **Numbers & Data Representation:** Decimal, binary, and hexadecimal conversions, Python conversion scripts, and ASCII/UTF-8 text encoding.
* **Version Control & Collaboration:** Git staging/commits, branching (`update-about`), and Pull Requests on GitHub.
* **Computer Networks:** LAN, MAN, WAN, DNS, routers, protocols, packet switching, client-server architecture, and how browsers load webpages.

## How to Run the Python Number Converter
To run the number-conversion program created in Mission 5:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive decimal integer when prompted to view its binary and hexadecimal equivalents.

## What I Learned
* **Command-Line & OS Fundamentals:** I learned how to navigate folders, manage files safely, combine command flags with pipes, and inspect processes and file permissions in Terminal.
* **Programs & Data Representation:** I learned the difference between compiled and interpreted languages, converted values across decimal, binary, and hexadecimal bases, and built a working Python converter.
* **Version Control & Networking:** I learned how Git tracks snapshots cleanly per mission, how branches and Pull Requests isolate changes, and how DNS, routers, and protocols work together when opening a website.
